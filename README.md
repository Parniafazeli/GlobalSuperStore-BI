# GlobalSuperStore-BI
Power BI dashboard built with the Global Superstore dataset.

### Tools & Technologies
- SQL Server
- SSMS
- SSAS Tabular
- Visual Studio
- DAX
- Power Query
- Power BI

### Data Preparation

- Imported the Global Superstore dataset from Excel
- Cleaned and transformed the data using Power Query
- Stored the prepared data in SQL Server
- Built a Tabular data model using SSAS
- Created DAX measures for business analysis

### Project Workflow
Excel → Data Cleaning → SQL Server → SSAS Tabular → DAX → Power BI 

### Dashboard
Interactive Power BI dashboard for Executive Overview, analyzing sales, profit, customers, products, returns, and geographic& marketing performance, Shipping & Logistics
